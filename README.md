# 🎮 HEAD TETRIS

웹캠으로 **고개 움직임**을 인식해서 조작하는 테트리스입니다.

---

## 조작법

| 동작 | 효과 |
|------|------|
| 고개 **좌우로 돌리기** | 블록 좌우 이동 |
| 고개 **좌우로 기울이기** | 블록 회전 (기울기 우선) |
| 고개 **아래로 숙이기** | 블록 바닥으로 즉시 낙하 |

> 키보드로도 조작 가능: `←→` 이동 / `↑` 회전 / `Space` 즉시 낙하 / `Z` 반시계 회전

---

## 실행 방법

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. 실행

```bash
python tetris.py
```

### 3. 시작

- 게임 실행 후 **캘리브레이션**(보정)이 진행됩니다 — 정면을 보고 가만히 기다리세요
- 보정 완료 후 **Enter** 키를 눌러 시작
- 게임 오버 후 **R** 키로 재시작
- **F11** 전체화면 / **ESC** 종료

## 게임 규칙

- 줄 **10개**마다 레벨 업, 레벨이 오를수록 블록이 빨라짐
- 한 번에 지우는 줄 수에 따라 점수 배율 상이

| 클리어 | 점수 |
|--------|------|
| SINGLE | 100 × 레벨 |
| DOUBLE! | 300 × 레벨 |
| TRIPLE!! | 500 × 레벨 |
| TETRIS ✦ | 800 × 레벨 |

---

## 기술 스택

- **pygame** — 게임 렌더링
- **OpenCV** — 웹캠 캡처
- **MediaPipe FaceMesh** — 얼굴 랜드마크 추적 (눈, 코, 턱)
- 고개 **yaw**(좌우 회전) / **roll**(기울기) / **pitch**(고개 숙임) 계산으로 제스처 인식
